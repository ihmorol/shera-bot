## Decision and rationale

**Storage is row-based SQLite, not a filesystem.** `workspace_nodes` rows keyed by (workspace, parent, name) with typed scopes (`workspace://` and `agent://<agent-id>/`). This makes symlink-escape structurally impossible (there is no path-to-inode resolution), so the traversal AC is enforced entirely at URI resolution: percent-decoding happens BEFORE the safety checks, and `..`, encoded traversal, backslashes, null bytes, malformed escapes, and foreign schemes are all typed refusals (pinned per-case). The trade-off recorded for review: files live inside the SQLite database (BLOB content), sized for the prototype; a filesystem-backed store would reintroduce the symlink/toctou class for no prototype benefit.

**Write leases (D6) use the established holder/expiry/revocation vocabulary on a `write_leases` table, task-scoped by NOT NULL task_id.** Exclusive per canonical path (canonicalized through the same scoped-URI parser, so encoding spellings collide); renew is holder-task-only; expiry is injectable-clock; steal-by-expiry gives the path to a new acquirer and records the lapsed row released; `releaseLeasesForTask` is the ONLY runtime force-release and is invoked at task-terminal wiring (API seam shipped; automatic call-on-terminal-transition is a recorded deferral below). User writes to a path under an ACTIVE agent lease are refused with the conflict payload naming holder agent (id + resolved display name) and task — the tooltip data rendered verbatim by the web editor ("Developer is editing this file · task #N"). User delete passes through the same gate (review round F1): agent-held active leases block on the exact path and, for directory deletes, the canonical-path subtree (killing the claimed-but-unwritten resurrection variant); passing deletes purge released/expired rows; user-held leases never block and outlive deletes until their task terminates. Agent delete is the typed `AGENT_DELETE_REQUIRES_APPROVAL` refusal (G6: the approval path is S20's), and agent mkdir is the one documented ungated mutation (structural directories, pinned). No silent overwrite or silent delete exists on any path.

**The panel is a pure state machine over the S08 shell's reserved resizable region.** Semantic states 0 → 360px → 50% → full-page route `/app/chat/[chatId]/workspace/full` (deep-linkable per tab via `?tab=`, validated server-side); the `react-resizable-panels` separator (S08 dependency, reused — no new panel deps) is the single resize handle with pointer drag AND built-in ARIA keyboard; the controller drives geometry imperatively with de-dup so commands and the handle cannot fight (the "conflicting simultaneous control must be impossible" AC is structural, pinned by test). Per-conversation width persists in localStorage keyed by chat id through an injectable Storage seam (first client-persisted preference in apps/web); mobile (<768px) renders a bottom sheet with its own translateY animation token; "Back to chat" is state-aware — in-app arrivals history-back with state restored, deep links get "Go to dashboard".

**The four S7 tabs are real data surfaces on the authenticated local API through the browser proxy.** Files (tree/upload/download/delete-behind-named-confirm/folder-create), Editor (CodeMirror 6, Mod-S/save button, dirty state, binary files get an honest read-only notice, lease conflict disables editing with the API's tooltip while content stays readable), Private files (per-Agent viewer with roster selector, actor-parameterized reads, D39 copy verbatim), Artifacts (cards with type/name/size/producer/"from run #N", inline preview of small text artifacts from real bytes, byte-exact download). A latent wire-format bug was caught during capture verification and pinned: the API serializes `is_directory` as SQLite INTEGER, the web read model now normalizes 0/1→boolean.

**CodeMirror 6 adoption (E-note per the OSS policy).** `codemirror@6.0.2`, `@codemirror/state@6.7.6`, `@codemirror/view@6.43.15`, `@codemirror/commands@6.11.1`, `@codemirror/language@6.13.1` — all MIT, on the S01 allowlist; license-inventory green; exact-pinned after review (no `^` drift). Chosen over Monaco per the issue's leverage note (lighter, mobile-friendly per PRD §18); client-only, themed from design tokens.

**Browser trust boundary:** `isBrowserRuntimePath` (packages/contracts) gained the workspace reads and typed writes exactly, with the runtime-internal `release-for-task` route explicitly excluded and pinned by contract tests; the web proxy parses PUT/DELETE bodies so the tenant-binding check (`runtimeWorkspaceMatches`) holds for workspace mutations.

## Alternatives considered (preserved)

- **Filesystem-backed file store** (real dirs under a container volume): rejected — reintroduces symlink-escape and traversal-to-FS classes the row model eliminates; BLOB-in-SQLite keeps AC16 persistence a reopen test.
- **Beside-the-chat bespoke dock**: superseded during chunk 4 — the S08 shell already reserved a `react-resizable-panels` workspace region; mounting there makes the library's ARIA splitter the one handle and satisfies "no conflicting control" structurally.
- **jsdom component tests**: unavailable (dep set frozen); tests follow the established node + renderToStaticMarkup + source-read conventions, with the pure panel reducer carrying the state-machine coverage and the library owning splitter interaction.
- **Keeping `listWorkspaceLeases` client schema**: removed (review F2) — zero callers and a shape that could not parse the server's flat rows; re-add with a consumer when a surface needs it.
- **Persisting active tab client-side only**: superseded — the full-page route validates `?tab=` server-side and syncs via `router.replace`, making the AC's "deep-links to a specific panel" honest.

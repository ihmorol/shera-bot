# Triage Labels

The five canonical triage roles, each label string equal to its name:

- `needs-triage` — newly filed, not yet assessed
- `needs-info` — blocked on an unanswered question
- `ready-for-agent` — specified, unblocked, may be picked up by an agent
- `ready-for-human` — needs the owner (sensitive mutations, product decisions, brand assets, owner review gates)
- `wontfix` — deliberately out of scope

Note: the slice tracker (issue #1) already uses this vocabulary verbatim (2026-09-17, before these skills were installed) — no overrides required.

## How to run the automated legs

```bash
pnpm acceptance        # the criteria runner: executes the ledger's automated rows
                       # (batched vitest Tier 1 + the §18 browser matrix Tier 2),
                       # writes tests/acceptance/evidence/<date>/acceptance-report.{json,md}
```

The runner's honesty rules are executably pinned in its header (`scripts/acceptance-runner.ts`): a missing/failing/pending-merge mapped test leaves the run RED (G4); a browser binary that cannot be obtained is recorded NOT-VERIFIED with its reason, never faked; live-provider rows are never executed (G7 — opt-in only); the E43 leak-scan rule (findings report category + path, never content) guards the ledger, the fixture area, and every report before anything is written.

Default CI stays bounded: `pnpm test` (which includes the ledger's own honesty contract) + lint/typecheck/guards. `pnpm acceptance` is the separate, explicit full-ledger gate.
